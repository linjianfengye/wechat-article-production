# 秀米公众号推文技能

一套用于 Codex 的技能。通过 Windows MCP 在秀米中搜索与预览模板，在目标稿使用局部模板组件，再按 Word 顺序替换文字、照片和图注。可根据模板风格生成配套标题图，并在手机预览中检查成稿。

## 使用

把 `wechat-article-production` 文件夹放进 Codex 的用户技能目录。调用 `$wechat-article-production`，提供 Word 或其他已确认稿源，以及要续排的秀米原稿链接。需要在浏览器中登录时，由用户在秀米页面完成。实际排版需要可用的 Windows MCP。制作新标题图需要宿主的生图工具。
