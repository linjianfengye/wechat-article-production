# 秀米公众号推文

1. **定位稿件和素材。** 用图文编号、标题和已排内容确认目标。指定 Word 时，以其文字、图注和图组顺序为准。新写稿按已确认资料组织。详见 [写作与素材](references/production.md)。
2. **在秀米找模板。** 用 Windows MCP 打开秀米，检查登录和 VIP。未登录由用户登录，无明确有效 VIP 时只选确认免费的款式。打开模板库，搜索并查看实际预览。记录选中的可见名称或链接及拟使用的正文组件。已指定模板时直接打开核对。只有推荐需求时，到这里交付候选。
3. **把模板组件放进目标稿，预览一节。** 确认正文、标题和图注字体，已明确沿用的格式直接沿用。用 Windows MCP 在目标稿实际插入、替换或复用选中模板的局部组件，优先完成一节有真实文字和代表性图组的排版，预览确认卡片、留白、图组和图注效果。使用局部组件完成套版，禁止使用「一键套模板」或整篇应用。详见 [模板搜索、落位和逐块替换](references/xiumi.md)。
4. **按实际版式制作标题并排完。** 样节确认后，调用自己的生图功能，按实际标题槽、背景和模板风格制作带正式文字的主标题及各节标题图。对照 Word 将其余图文逐块放进所选模板的对应局部组件。详见 [模板配套艺术字](references/production.md#模板配套艺术字)。
5. **验收。** 在手机预览中逐节核对模板正文组件、图片顺序、图注、字号和标题。保存后核对图文编号。交付实际使用的模板名称和已应用的正文组件。只有标题图、选款记录或外部预览时，套版仍未完成。公众号草稿和发布按各自授权执行。
