# 秀米模板选择与原稿续排

## 自动打开浏览器并检查账号

**秀米操作统一使用 Windows MCP。** 发现并使用 `mcp__windows_mcp` 的可用工具来截图、识别窗口、点击、输入和上传。首次操作前读取当前窗口和页面。此流程指定 Windows MCP，不改用 Computer Use、CUA 或其他浏览器自动化。Windows MCP 不可用时说明具体情况，继续可独立完成的 Word 核对、文图对照和标题图准备。

1. 任务要求在秀米套版时，自动启动浏览器操作。优先接管用户指定或已经打开的秀米标签页。没有秀米标签页时，在用户指定的浏览器或可操作的真实浏览器中打开 [秀米官网](https://xiumi.us/)。有指定原稿链接时直接打开该链接。选择登录状态能延续的浏览器，不用无登录状态的网页抓取结果判断用户的账号。
2. 先检查当前页面的登录状态。可访问「我的秀米」和账号菜单，并能确认当前账户时继续。若出现登录入口、扫码页或会话过期提示，保持页面打开，交由用户在浏览器内登录，例如「请在已打开的秀米页面扫码登录，登录成功后告诉我，我会接着选模板和排版。」等待期间可以整理文案和配图。恢复时重新检查同一个浏览器的登录状态，回到原稿并核对编号。让用户在页面内完成登录、验证码和扫码。
3. 登录后，通过当前账号菜单里的「我的会员」、会员权益页或其他明确的会员状态信息，检查是否有仍有效、适用于当前模板的 VIP 权益。头像、普通等级（如 LV.1）、会员促销入口和能预览模板都不能证明有 VIP。没有有效 VIP、已过期或状态无法确认时，按免费账号处理，继续找所有账号均可免费套用的模板。
4. 有效 VIP 可考虑账户现有权益覆盖且无需另付费的模板。无 VIP 时优先使用实际界面里可见的免费筛选、免费标记或可确认免费使用的系统模板。筛选入口不存在时逐个看候选详情和使用条件；能预览或没有标价并不能确认免费。遇到购买、开通或扣米点的提示，关掉提示，换下一款免费的候选；免费整套不合适时用免费的标题、卡片和布局组件拼成同一风格。没有可确认免费的候选时说明实际页面限制。
5. 账号权限确认后，马上进入模板库找候选。字体确认与制作配套标题安排在选定模板之后。

## 进模板库实际搜索并预览

1. 账号检查后先打开秀米的模板库，再开始套版。在秀米首页找「挑选风格排版」或当前显示的模板入口；也可在原稿编辑器通过「图文模板」→「样刊模板」「更多模板」或搜索入口。已有原稿时保持原稿打开，使用模板面板或另一个浏览器标签看候选。如果首个入口只显示零散单个组件，补看样刊或风格排版库。
2. 用稿件类型、主题、色调和主要图组组合搜索。校园科技活动可先搜「校园 科技」「活动回顾」，按结果改用单词或换「比赛」「作品展示」。没有搜索时浏览相关分类。打开候选详情或预览，实际查看封面、正文卡片、标题做法和图片区；只将账号可套用且无需另付费的款式加入候选。
3. 对至多三款有代表性的候选比较主题匹配度、图文容量、可编辑性和手机端的清晰度。候选接近时优先选对原有内容改动小的一款。选定后记录实际可见的名称或链接，并记下主辅色、底纹形状、标题字形特征、装饰和标题可用尺寸。这个结果是制作艺术字和套版的依据。仅有截图或暂时进不去模板库时，明确说明已核实的范围；只有用户授权根据截图设计时才进入该方案。
4. 记下可复用的位置和组件，再按下一节把选中款式落到目标稿。

## 在目标稿使用真实模板组件

- 全篇样刊用于看样式。套版时须在目标稿使用选中款式的局部组件，例如正文白底卡、信息框、并排图或图注分隔。可从模板面板插入单个组件，从可访问的参考稿复制单个组件，或复用目标稿中已经属于该款的原生组件。检查实际稿件里出现相应的版式属性。禁止点「一键套模板」或整篇应用。
- 先挑一节同时有正文和代表性图片的内容，按 Word 对照放入选中的正文卡片和图组组件。打开手机预览，检查背景衔接、段落边距、图片尺寸、图注和节间留白。以实际放入的组件宽度和背景确定主标题与小节标题图，再调用生图。已有标题图可在套好正文模板后检查并按需适配。
- 如果成稿只是插了标题图、正文仍是零散的文字和图片，应保留已核对的内容，将它逐节迁入所选模板组件。选中样式在当前账号不能用时，从模板库另选可用款式。模板库打不开或组件插不进去时，记录实际卡点，保留已排内容并报告进度，勿把自由排版当作完成套版。

## 逐块替换 Word 内容

1. 先打开用户确认的 Word，按正文顺序建立简短对照表。列出导语、各节标题、段落、信息框、图片、图组和图注的来源位置。图片用 [取图方法](production.md#从-word-按顺序取图) 按出现顺序导出。以 Word 的图文关系为准，保留表格里的图、并排左右顺序和重复使用的图片。
2. 用 Windows MCP 打开目标秀米图文和布局模式，检查每个候选位置的宽高、背景、层级和作用范围。结合段落长度、照片比例、图注位置和手机阅读来选位置。遇到构图不合适的图片槽就换组件或调整布局。现有稿以已排末尾和用户指定位置为锚点；保留白底框、字号、首行缩进和已确认的内容。**完整样刊只用于预览和参考。任何稿件都不点「一键套模板」或整篇应用。** 空白稿也按实际内容选取、搭建或插入局部组件。
3. 依照对照表在对应位置逐块替换。逐段替换示例文字，逐张替换示例照片，把各图注放到对应图组下。选中单张图再从「我的图库」选对应文件，确认结果是替换。缺少合适位置时先插入合适的标题、卡片、布局或图片组件，再填内容。每节做完对照 Word 核对完整性。单独把生图制作的主标题和各节标题图放到已确认的位置。
4. 正式内容齐全以后才删除不使用的占位文字、样图和多余空框。套版任务须看到实际原稿里的替换结果，并在手机预览里核对后再报告完成。

## 局部组件操作

1. 继续用 Windows MCP 操作。结合图文编号、标题、已排内容确认目标。区分参考稿与目标稿。续排前在布局模式查看白底卡片、外层主题底图、嵌套布局、段落和空行。获取原有字号、字体、首行缩进、行距及边距用于给用户确认。
2. 同账户已排好参考稿时，点卡片内边距，确认选中边框包住正文和整个图组。用组件工具栏「复制」加入左侧「剪贴板」。混合多选若没有复制功能，逐组件复制。用同一编辑器顶部「打开」切换图文，部分界面需要双击条目。切到目标后再次核对图文编号和剪贴板内容。刷新页面可能清空剪贴板。
3. 用「前插空行」或「后插空行」建立明确插入点，选中新空段落再点剪贴板条目。光标停在正文里时插入组件可能切断该段。需要从固定开头倒序插时，每次在当前首组件前新建空行。每次确认新卡片在正确层级，没有误放进标题或正文内部。
4. 导入 DOCX 时，实测秀米曾漏掉表格内的图片，直接粘贴富文本也可能丢图。优先用可编辑原生卡片加原生图库图片。用导出的图序清单按节上传，选择具体文件名，核对缩略图并排顺序。有并排要求时，可保持原生组件或按用户需要组合成一行图片。
5. 补正文可从相同角色的原段使用「提取格式」，再应用到目标段。先确认选中的是整个目标段，随后核对实际字体、字号、行距和首行缩进。用户确认换字体时同步检查原参考卡片是否带来旧字体。替换小节标题图时选中单图，在「我的图库」点相应图片，检查是真替换而非额外插入。

## 清理、验证与保存

- 先确认正式内容齐全，再按选中边框清理模板示例、空行和版权示例。检查有没有拆开的占位字样、古诗、示例图片或空卡片，避免删到已排正文。
- 用原有模板保留用户已经排好的封面与导语。需要更新的元数据以已确认文案为准。预览正文头图和管理页方形缩略图，分别检查裁切。
- 用手机预览从封面到末段核对文字、图注、对照源稿的图组顺序、白底卡片、缩进及章节留白。用户授权保存时使用确认过的原稿地址，重新打开验证持久化。完成后恢复正常缩放和视图。遇到需要用户登录、扫码或接管桌面时暂停交由用户。
